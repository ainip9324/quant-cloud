# EMA 交叉信号、ATR 风控与低波动过滤 v4

适用于 execution.version=1、strategyVersion=ema20-signal-v1、risk.version=3。实际参数以任务快照为准。

- EMA_CROSS_ENTRY_EXIT。闭合 K 线上穿 EMA 产生开多候选，下穿产生开空候选。持仓期间反向穿越发出退出信号。
- LOW_VOLATILITY_FILTER。开仓候选使用本根闭合时的 ATR(20)，与上一根闭合时的 ATR(60) 比较。默认低于基线的 0.60 倍时过滤。至少需要 62 根已闭合 K 线形成比较，基线未就绪或波幅为零时过滤。配置为 0 时关闭该过滤。过滤只针对开仓，回放记录 ENTRY_FILTERED_VOLATILITY。
- NEXT_BAR_EXECUTION。有效信号在下一根可执行 K 线开盘撮合。开盘跳空先处理已有仓位保护，按开盘价退出。新仓同根也检查保护。OHLC 同时触发时优先强平，其次止损，再次止盈。
- CONFIGURED_PROTECTION。止损使用信号收盘时确定的 ATR 乘配置倍数，围绕开盘成交价设置。止盈距离为初始止损距离乘配置盈亏比。保护价在持仓期间固定。
- CONFIGURED_RISK_SIZING。NOTIONAL_RATIO 用权益乘 allocation 再除以开盘价。STOP_RISK 用权益乘 allocation 后除以初始止损距离。实际亏损还受手续费、跳空和强平影响。
- MARGIN_CHECK。保证金和手续费不足时整笔拒绝。该 EMA 风控版本取消总名义仓位上限。回放记录候选数量、保护价和准入结果。
