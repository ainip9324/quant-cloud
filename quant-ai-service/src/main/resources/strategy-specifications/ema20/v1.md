# EMA20 v1

- Minimum data: `emaPeriod + 2` K-lines; default `emaPeriod=20`, so the registry advertises a minimum of 22 bars for the default.
- Entry: a close crossing from at/below the prior EMA to above the current EMA opens LONG; crossing from at/above the prior EMA to below the current EMA opens SHORT.
- Exit: a LONG closes on the opposite (down) cross; a SHORT closes on the opposite (up) cross. The strategy does not reverse on the same K-line.
- Position sizing uses `positionRatio` of equity (default `0.01`). Default fixed risk settings are `stopPoints=100` and `takeProfitPoints=100`; long uses entry minus/plus those points, short mirrors them.
- It does not add to a position. Stop and target execution is handled by the common engine.
- Known limitation: these are fixed point distances, not volatility-normalized values.
